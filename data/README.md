# Data

This directory contains lightweight configuration and example inputs.

Do not commit large proprietary, unpublished, or generated structural/simulation datasets unless appropriate.

Recommended inputs include:

- PDB structures or structure identifiers
- reference FASTA sequences
- chain/design specifications
- fixed-position specifications
- ProteinMPNN configuration files

The current repository uses small example metadata rather than claiming project-specific ProteinMPNN results.
