# Case Study: Sotrovimab Redesign

## Purpose

This folder is a placeholder for documenting a structure-guided redesign study of the sotrovimab antibody.

A suitable case-study workflow is:

```text
Antibody–antigen structure
        ↓
Interface/residue analysis
        ↓
Define redesign positions
        ↓
ProteinMPNN sequence generation
        ↓
Sequence filtering
        ↓
Structure prediction
        ↓
Interface / stability analysis
        ↓
Optional docking and MD
        ↓
Candidate prioritization
```
